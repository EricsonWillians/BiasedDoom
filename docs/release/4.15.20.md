# BiasedDoom 4.15.20

BiasedDoom 4.15.20 adds the player-hosted online-play foundation and the
local experimental-camera work, while making the out-of-box presentation and
camera behavior explicitly classic by default.

## Vanilla First Launch

New configurations now open with **Vanilla+** graphics, **Classic Balanced**
lighting, and **Disabled** fog. Optional bloom, grading, CRT/VHS, lens, color,
and BiasedDoom global-fog effects all start inactive. The engine does not
remove fog authored by a map; that remains normal Doom content behavior.

Saved configurations keep their own choices. Use **Reset to Vanilla Doom** in
the Rendering Presets menu (or `resetrenderpresets`) to apply the same baseline
to an existing profile.

## Normal Camera First

New configurations start in ordinary first-person view. Third-person,
Photo Mode / Free Camera, and Top-Down are optional modes, not startup modes.
Experimental camera shortcuts and their menu controls remain local-only and
are unavailable in demos and netgames.

Top-Down now has cursor-driven mouse, stick, gyro, and keyboard aim; animated
actor markers; interactive-line markers; classic vertical autoaim; orthographic
framing; and a free-pan offset that is retained when follow mode resumes.

## Online Play And Reliability

The online-play foundation adds player-hosted public browsing and join codes,
encrypted relay fallback, host-reviewed mod transfer, reconnect,
join-in-progress, and host recovery. Read the
[online multiplayer guide](../engine/online-multiplayer.md) before hosting a
session.

Linux OpenAL initialization is bounded to prevent a startup hang. CI and
release jobs now install the `curl` and `unzip` prerequisites required by the
pinned vcpkg bootstrap, so clean workers do not depend on tools preinstalled
by a hosted image.

## Validation

The release gate covers the native online-core and snapshot-fuzz tests, online
service and Redis integration, containerized HTTPS service health, Python
framework contract tests, workflow and shell linting, and package builds on
Linux, macOS, Windows, and MinGW. The preset-link integration test also checks
the fresh vanilla rendering and normal-camera defaults when supplied an IWAD.
