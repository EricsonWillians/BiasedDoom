# Engine Feature Docs

These guides cover non-glTF engine features and gameplay-facing systems.

- [IWAD discovery](iwad-discovery.md) — automatic Steam/GOG/platform search,
  `-findiwads` diagnostics, short names, and custom paths.
- [Rendering presets, bloom, and sector light bleed](rendering-presets.md) — searchable preset browsers, bloom tuning, sector-light fades, and live backend switching.
- [Gamepad support](gamepad.md) — classic-first default layout, layout presets with coherent aiming-model coupling, vanilla vertical autoaim and the `bd_classic_autoaim` override for `+WEAPON.NOAUTOAIM` mods (Brutal Doom), gyro look, and sound-driven haptics.
- [Recording and export](recording-and-export.md) — lossless PNG/RGB-AVI capture, configurable export folders, native demo takes, and recording shortcuts.
- [Procedural map generation](procedural-map-generation.md) — the current recipe-to-UDMF pipeline, automatic run blueprints, accessibility contract, Doom I/Doom II support, endless-run flow, and regression commands.
- [Procedural generation research paper](procedural-generation-research-paper.md) — mission-graph model, spatial synthesis, UDMF contracts, and clearly labeled historical evaluation data.
- [Mugshot scaling](mugshot-scaling.md)
- [Mugshot tutorial](mugshot-tutorial.md)
