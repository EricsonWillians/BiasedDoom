- [Procedural map generation](procedural-map-generation.md) — player controls, five themes, hierarchical architecture, macro liquids, reveals, perches, and regression commands.
- [Procedural generation research paper](procedural-generation-research-paper.md) — mission-graph model, spatial synthesis, UDMF contracts, and 4.15.6 evaluation.
